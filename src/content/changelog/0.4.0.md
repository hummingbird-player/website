## General
- **feature** Hummingbird has been redesigned. (@143mailliw)
- **feature** A reduced motion option has been added. (@angelwings)
- **feature** Navigation actions have been added to the command palette. (@angelwings)
- **feature** A command palette action to open the theme folder has been added. (@angelwings)
- **feature** Added a "slim" scrollbar option that shrinks the scrollbar width when not in use. (@Adolar0042)
- **feature** Improved CPU and memory utilization. (@143mailliw)
- **feature** The 'Open in File Manager' context menu item has been added to context menus where it was missing. (@angelwings)
- **improvement** Added 2 new languages:
  - **improvement** Simplified Chinese (Mainland China) (@mengh04)
  - **improvement** Italian (@giallorosso84)
- **improvement** A warning is now shown when a legacy theme file is detected. Support for legacy theme files will be removed in 0.5.0. (@angelwings)
- **improvement** Caret manipulation in text fields has been significantly improved. (@angelwings)
- **improvement** The command palette can now be searched by keybind. (@143mailliw)
- **fix** The command palette can no longer be opened while another modal is open. (@angelwings)
- **fix** Escape now closes context menus. (@angelwings)
- **fix** It is no longer possible to open the settings window an unlimited number of times. (@angelwings)
- **fix** Pop-ups that would re-open themselves after being cloesd no longer do so. (@angelwings)

## Windows
- **feature** The audio pipeline used on Windows now uses the same backend code as other platforms. This eliminates some feature disparities. (@143mailliw)
- **feature** Hummingbird now displays a warning when the default audio device is in use by another application in exclusive mode. (@143mailliw)
- **fix** Fixed some missing system media integration features. (@143mailliw)
- **fix** Opening an item in file manager should work more reliably. (@143mailliw)
- **fix** Windows on ARM now uses the same AAC decoder as other platforms. (@143mailliw)

## Linux
- **feature** Added PipeWire support. (@143mailliw)
- **feature** Hummingbird should now work more reliably with low-latency audio configurations. (@143mailliw)
- **feature** Lyrics are now exposed over MPRIS. (@mengh04)
- **feature** Added an option to send audio directly to the audio server without Hummingbird resampling or converting it. In some cases, this allows for bit-perfect playback. (@143mailliw)
- **fix** Album artwork is now sent over MPRIS in a manner which is compatible with the GNOME desktop. (@143mailliw)

## Library
- **feature** Added a Files view. (@143mailliw)
- **feature** Playlists can now be automatically sorted. (@angelwings)
- **feature** Playlists and albums now display their durations and track counts. (@vluna.codeberg)
- **feature** The scanner now uses a more reliable metadata decoder. (@143mailliw)
- **feature** Tables can now be horizontally scrolled. (@mengh04)
- **feature** Hummingbird can now parse additional metadata to determine when multiple artists contributed to a track or album. (@143mailliw)
- **feature** Albums now have an "Add to Playlist" context menu item. (@andreadev)
- **feature** Individual tracks (ones not associated with an album) are now available in the library. (@143mailliw)
- **feature** Genres are now displayed in the library. (@143mailliw)
- **feature** The album table now has (disabled by default) track count and duration columns. (@143mailliw)
- **feature** You can now export the liked songs of a specific artist through the command palette while on that artist's page. (@143mailliw)
- **feature** Artists now have a context menu. (@angelwings)
- **improvement** Scroll positions are now remembered when navigating between library views. (@angelwings)
- **improvement** Large libraries should now respond faster. (@143mailliw)
- **improvement** More complex track numbers (for example, A1, 2.1, and AA) are now supported. (@143mailliw)
- **fix** Scrollbars no longer show when unnecessary on detail views. (@143mailliw)
- **fix** Sorting now handles non-Latin scripts correctly. (@143mailliw)
- **fix** Navigating to the same page repeatedly no longer causes copies of that page to accumulate. (@143mailliw)

## Queue
- **feature** Changes to the queue can now be undone. (@143mailliw)
- **feature** Multiple queue items can now be selected and reordered. (@angelwings)
- **feature** Selected queue items can now be dragged in to playlists. (@143mailliw)
- **feature** An option to make the queue remove tracks after they finish playing has been added. (@angelwings)
- **feature** When scrolled away from the current track, a "Jump to current" button is now available. (@143mailliw)
- **improvement** The queue now centers on the current track rather than scrolling to it. (@143mailliw)
- **fix** Track removal no longer causes the UI to desync from the actual queue state. (@angelwings)

## Playback
- **feature** An option to inhibit sleep while audio is playing has been added. (@angelwings)
- **feature** Playback can now be stopped after the current track ends. This option is available through the context menu of the play/pause button. (@angelwings)
- **feature** Loop point tags are now handled properly. (@143mailliw)
- **feature** Hummingbird now automatically mixes audio from the input channel count to the output channel count. (@143mailliw)
- **feature** Added an equalizer. (@143mailliw)
- **improvement** The responsiveness of the playback controls has been improved. (@143mailliw)
- **fix** Recoverable playback errors will no longer cause crashes. (@143mailliw)
- **fix** Fixed some minor gapless playback issues. (@143mailliw)
- **fix** Fixed some accuracy issues with certain bit-depths. (@143mailliw)
- **fix** Improved memory usage and allocation behaviour. (@143mailliw)
- **fix** The lyrics are no longer automatically scrolled while paused. (@143mailliw)
- **fix** The UI no longer desyncs from the actual engine state after restarting the application. (@angelwings)
- **fix** It is no longer possible for tracks to have metadata in the queue but not the current track display. (@143mailliw)

## Scanner
- **feature** Added a slow disk mode that prevents multiple simultaneous disk reads, reducing random reads. (@angelwings)
- **feature** The scanner now handles case-insensitivity on all operating systems. (@143mailliw)
- **feature** The scanner now automatically watches for changes in your music library. This can be disabled in the settings. (@143mailliw)
- **improvement** The scanner now uses the most common album artwork as the album cover, rather than the first available image. (@143mailliw)
- **fix** Windows album artwork thumbnails are now ignored by the scanner. (@143mailliw)
- **fix** ID3v2 tags are now prioritised over other metadata sources. (@143mailliw)
- **fix** "Ghost tracks" should no longer occur, and existing ones should be automatically cleaned up. (@143mailliw)
- **fix** APE tags are now used only when no other metadata source is available. (@143mailliw)
- **fix** The filename is now used when no other metadata source is available. (@angelwings)

## Services
- **feature** Added support for ListenBrainz scrobbling. (@angelwings)
- **fix** Restarting the Discord RPC service is now more reliable. (@angelwings)
