**For the full changelog, see [the Changelog page](/changelog#v0-4).**

Hummingbird 0.4 is now available, bringing massive improvements to stability and a few new features. Here's some of the highlights:

# Redesign
![Image of the redesigned UI](/assets/0.4.0/screenshot.png)

Hummingbird's UI has been redesigned to emphasize each resizable section more clearly, and reduce visual noise while improving density and readability. This has been an on-going change throughout 0.4's development, and we'd love to hear what you think about it in our Discord. We expect to continue making improvements to the UI in future releases.

# Equalizer
![Image of the equalizer UI, with several bands adjusted](/assets/0.4.0/equalizer.png)

Hummingbird now comes with a built-in equalizer, available in the Settings window. It supports up to 16 bands, with 5 filter types available in a graphical editor.

# Files View
![Image of the files view, with the folder "(What's the Story) Morning Glory?" by Oasis expanded](/assets/0.4.0/files.png)

The library now includes a long-requested file tree view, allowing you to browse your music library's files and folders.

# Library Improvements
![Two non-album tracks in the library](/assets/0.4.0/artist_tracks.png)

The library system has been rewritten to substantially improve flexibility. It now supports multiple artists contributing to tracks and albums, tracks not associated with an album, track-specific cover art, genres, and more complex track number formats, to name a few improvements. Additionally, the scanner's relability has been substantially improved, and it has better support for case-sensitive file systems.

# The Smaller Stuff
There's a ton of smaller improvements in this release as well:
- The queue has seen a ton of minor improvements, including multi-select, undo, and dragging items into playlists.
- Playback is now significantly improved, with all remaining accuracy bugs fixed and tests added to prevent future regressions.
- Support for ListenBrainz scrobbling.
- Significantly reduced CPU and memory usage. If you used grid view, you may notice up to a 75% reduction in memory usage.
